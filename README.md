# 🎧 Mood to Playlist

A simple mood-based music discovery app.

## Features
- 6 moods: Sad, Hype, Heartbreak, Chill, Romantic, Angry
- Opens music searches on Spotify, YouTube Music and YouTube
- No signup/login required
- No API key required
- Simple dark UI with mood-specific visual feedback

## GitHub Pages

1. Upload this folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save and wait for GitHub Pages to publish.

Your pages will be available at:
- `/index.html`
- `/privacy.html`
- `/terms.html`
- `/contact.html`

## Before publishing

Replace:
- `YOUR_SUPPORT_EMAIL@example.com` with your real support email.
- The `Get it on Google Play` placeholder link in `index.html` with your actual Play Store URL.
- The GitHub link in `index.html` with your repository URL.
- App/developer details if you want them shown on the legal pages.
